# Happy Birthday Sumiya! 🎂✨

A personalized, highly interactive, and responsive Birthday Celebration Website built specifically for **Sumiya**.

## 🌟 Highlights
- **Midnight Countdown**: Dynamically counts down to 12:00 AM midnight.
- **Automated Celebration**: Fires realistic canvas fireworks, confetti ribbons, and "Happy Birthday" melody at 12:00 AM.
- **Interactive 3D Cake**: Blow out candles to make a wish with smoke particle effects and audio feedback.
- **Wax-Sealed Letter**: Tap to open a heartfelt parchment letter with customizable wishes.
- **Floating Balloons Playground**: Pop balloons to reveal sweet compliments.
- **Polaroid Memory Wall**: Upload custom photos right in the browser (persisted to localStorage).
- **Mystery Gift Box**: Unwraps to reveal a special Birthday Privilege voucher.
- **Zero External Dependencies**: Pure HTML5, CSS3, JavaScript, HTML5 Canvas, and Web Audio API. Works 100% offline and in all modern browsers.

## 🚀 How to Deploy to Vercel

### Option 1: Via Vercel CLI (Fastest)
1. Open PowerShell / Command Prompt in this folder:
   ```bash
   cd d:\happy_birthday
   ```
2. Run:
   ```bash
   npx vercel
   ```
   Follow the simple prompts (press Enter to accept defaults). Vercel will deploy and give you an instant live URL (e.g., `https://happy-birthday-sumiya.vercel.app`)!

3. For production deployment:
   ```bash
   npx vercel --prod
   ```

### Option 2: Via GitHub & Vercel Dashboard (Recommended for easy updates)
1. Push this project to a new GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Sumiya Birthday Website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/happy-birthday-sumiya.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New..."** -> **"Project"**.
4. Select your `happy-birthday-sumiya` repository.
5. Click **"Deploy"** (Vercel automatically detects the static configuration with `vercel.json`).
6. Your website is instantly live with free global CDN and HTTPS!
